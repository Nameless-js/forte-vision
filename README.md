# BlockWatch

Каркас Datathon: React + TypeScript + Python FastAPI, подготовка под локальный Supabase.
Главная в стиле пиксельного Overworld и рабочая станция проверки видео.

## Быстрый запуск

Node.js 20+ и Python 3.11+.

```powershell
npm install
npm run dev
```

Интерфейс: http://127.0.0.1:5173. Демо работает без сервера: загрузите своё видео и нажмите «Запустить анализ». Учебные события явно помечены и не анализируют содержимое видео.

Для Python API из корня проекта:

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -r backend/requirements.txt
$env:API_KEY='ваш-случайный-ключ'
.venv/Scripts/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

В интерфейсе откройте «Подключение», отключите демонстрационный режим и укажите ключ. Vite проксирует `/api` на порт 8000. Ключ не сохраняется в браузере. Если API_KEY не задан, сервер создаёт приватный ключ в `runtime/.api-key`.

## Подключение модели

Реализовать только `backend/model_adapter.py`, функцию `analyze_video(path)`. Синхронная функция получает путь к локальному видео и возвращает словарь:

```python
{
  'verdict': 'violation',
  'violations': [{
    'type': 'Подтверждённый тип события',
    'timecode_sec': 12.5,
    'description': 'Наблюдаемое действие и основание для проверки',
    'evidence_frames': [{'timestamp_sec':12.5, 'image_base64':'JPEG_BASE64'}],
    'rule': {'title':'Название источника', 'section':'Проверенный пункт', 'url':'https://...'}
  }]
}
```

Для отрицательного результата: `{'verdict':'no_violation','violations':[]}`. Модель пока намеренно возвращает ошибку «не подключена», а не выдуманный результат. API валидирует обязательные поля и JPEG. Кадры и таймкоды выбирает модель. Правила и источники не придумывать. Идентификацию лиц и облачные AI API не использовать.

## API жюри

`POST /api/v1/analyze` — multipart поле `file`, ответ 202 с `job_id`.
`GET /api/v1/jobs/{job_id}` — processing/done/failed и результат.
Оба маршрута требуют `X-API-Key`. Swagger: `/docs`. Health: `/api/health`.
Файлы до 100 МБ; до двух одновременных обработок. Задания хранятся в SQLite и переживают перезапуск; прерванные задания получают failed. Исходное видео удаляется после обработки.

## Supabase

Подготовлен необязательный серверный адаптер зеркалирования результатов через REST. Примените `supabase/schema.sql` к локальному Supabase, задайте SUPABASE_URL и SUPABASE_SECRET_KEY на Python сервере. React не получает секретный ключ. RLS включён, anon/authenticated не имеют доступа. При недоступности зеркала результат остаётся в SQLite. Действующее подключение не настроено: нужен ваш экземпляр Supabase. Для автономного контура используйте self-hosted Supabase: https://supabase.com/docs/guides/self-hosting/docker.

## Сборка и развёртывание

```powershell
npm run build
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

После сборки FastAPI отдаёт интерфейс из dist на том же адресе. Публичный URL и HTTPS настраиваются на сервере команды. Отдельный статический preview не запускает Python API. Не размещайте исходные видео в public/dist.

## Проверки

`npm run build` — TypeScript и production сборка.
`python -m pytest backend/test_api.py` — ключ API, неизвестный job, загрузка, ошибка неподключённой модели и валидация результата.

## Что ещё требуется до финала

Обученная локальная модель, подтверждённые нормативные правила, тест на новых видео, настройка Supabase и публичного HTTPS API. Ограничение 270 секунд завершает ожидание inference, но не останавливает поток модели: для реального GPU worker нужна изоляция отдельным процессом/очередью. Сейчас это каркас для одного процесса uvicorn, не multi-worker production.

MOV поддерживается при загрузке, но воспроизведение зависит от кодека браузера. Для неподдерживаемых кодеков добавьте локальную FFmpeg-конвертацию preview с сохранением временной шкалы. Шрифты включены локально; интерфейс не требует CDN.
