# BlockWatch

Каркас Datathon: React + TypeScript + Python FastAPI, подготовка под локальный Supabase.
Полноэкранный анимированный пиксельный Overworld и рабочая станция проверки видео.

Мир отрисовывается локально в Canvas: облака, птицы, мерцание воды, костёр, дым, гуляющая овца и сканер башни. Кнопка солнца/луны меняет сутки; пауза останавливает фон и CSS-анимации. Сундук открывает игровое достижение. Нижний инвентарь — навигация по функциям приложения. Учитывается prefers-reduced-motion. Пиксельный шрифт с кириллицей включён локально.

## Два оформления

В шапке доступен переключатель Minecraft / Forte. Банковский режим Forte Vision использует светлую палитру с бордовым акцентом, обычную типографику и плавные CSS-анимации. Игровой Canvas в нём не запускается. Тема запоминается в localStorage. Переключение не сбрасывает загруженный файл, результаты, вкладки, настройки и позицию плеера. Обработка и API одинаковы в обоих режимах.

## Быстрый запуск

Node.js 20+ и Python 3.11+.

```powershell
npm install
npm run dev
```

Интерфейс: http://127.0.0.1:5173. Демо работает без сервера: загрузите своё видео и нажмите «Запустить анализ». Учебные события явно помечены и не анализируют содержимое видео.

Для Python API из корня проекта:

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -r backend/requirements.txt
$env:API_KEY='ваш-случайный-ключ'
.venv/Scripts/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

В интерфейсе откройте «Подключение», отключите демонстрационный режим и укажите ключ. Vite проксирует `/api` на порт 8000. Ключ не сохраняется в браузере. Если API_KEY не задан, сервер создаёт приватный ключ в `runtime/.api-key`.

## Подключение модели

Реализовать только `backend/model_adapter.py`, функцию `analyze_video(path)`. Синхронная функция получает путь к локальному видео и возвращает словарь:

```python
{
  'verdict': 'violation',
  'violations': [{
    'type': 'Подтверждённый тип события',
    'timecode_sec': 12.5,
    'description': 'Наблюдаемое действие и основание для проверки',
    'evidence_frames': [{'timestamp_sec':12.5, 'image_base64':'JPEG_BASE64'}],
    'rule': {'title':'Название источника', 'section':'Проверенный пункт', 'url':'https://...'}
  }]
}
```

Для отрицательного результата: `{'verdict':'no_violation','violations':[]}`. Модель пока намеренно возвращает ошибку «не подключена», а не выдуманный результат. API валидирует обязательные поля и JPEG. Кадры и таймкоды выбирает модель. Правила и источники не придумывать. Идентификацию лиц и облачные AI API не использовать.

## API жюри

`POST /api/v1/analyze` — multipart поле `file`, ответ 202 с `job_id`.
`GET /api/v1/jobs/{job_id}` — processing/done/failed и результат.
Оба маршрута требуют `X-API-Key`. Swagger: `/docs`. Health: `/api/health`.
Файлы до 100 МБ; до двух одновременных обработок. Задания хранятся в выбранной базе (локальный Supabase или SQLite) и переживают перезапуск; прерванные задания получают failed. Исходное видео удаляется после обработки.

## Supabase

Локальный Supabase — основное хранилище при `DATABASE_BACKEND=supabase`. Docker Desktop должен быть запущен.

```powershell
npm install
npm run db:start
```

Первый запуск загружает контейнеры. Миграция `supabase/migrations/*_forte_vision_storage.sql` создаёт схему автоматически. Команда сохраняет URL и серверный ключ только в игнорируемый `.env`. Не публикуйте этот файл.

Затем запустите Python API и Vite. Для dev-сервера Vite ключ `API_KEY` подставляется в запросы `/api` только на серверной стороне: он не включается в React bundle. Dev-сервер слушает localhost. Для внешнего production-развёртывания требуется отдельная пользовательская авторизация или ввод API-ключа в интерфейсе.

* `analysis_jobs` — файл, размер, длительность, статус, режим demo/model, полный JSON результата, события и JPEG-доказательства.
* `analysis_events` — представление событий с таймкодами и нормативными основаниями без дублирования JSON.
* `normative_rules` — проверенный каталог правил; изначально пуст, выдуманные нормы не добавляются.

RLS включён; anon/authenticated не имеют доступа. Только Python-сервер использует secret/service_role ключ. Исходные видео остаются локальными и удаляются после обработки. Supabase здесь не связан с облачным проектом.

`GET /api/health` реально проверяет доступность БД и сообщает storage. `GET /api/v1/jobs` возвращает последние проверки (без тяжёлых кадров), `GET /api/v1/jobs/{id}` — полный результат. `POST /api/v1/demo/jobs` сохраняет явно помеченный учебный пример без передачи видео. Если backend подключён, демонстрационный результат из интерфейса также сохраняется в БД. Без backend демо остаётся только в памяти браузера.

Studio: http://127.0.0.1:54323. API Supabase: http://127.0.0.1:54321. Для автономного запуска без Docker можно явно выбрать `DATABASE_BACKEND=sqlite`; переключение не переносит данные между хранилищами.

После восстановления/перезапуска Supabase можно повторить `npm run db:configure` и перезапустить API/Vite. Локальную базу останавливайте через `npx supabase stop`, не используйте `--no-backup`, если нужны сохранённые данные.

## Сборка и развёртывание

```powershell
npm run build
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

После сборки FastAPI отдаёт интерфейс из dist на том же адресе. Публичный URL и HTTPS настраиваются на сервере команды. Отдельный статический preview не запускает Python API. Не размещайте исходные видео в public/dist.

## Проверки

`npm run build` — TypeScript и production сборка.
`python -m pytest backend/test_api.py backend/test_storage.py` — ключ API, неизвестный job, загрузка, ошибка неподключённой модели и валидация результата.

## Что ещё требуется до финала

Обученная локальная модель, подтверждённые нормативные правила, тест на новых видео и настройка публичного HTTPS API. Ограничение 270 секунд завершает ожидание inference, но не останавливает поток модели: для реального GPU worker нужна изоляция отдельным процессом/очередью. Сейчас это каркас для одного процесса uvicorn, не multi-worker production.

MOV поддерживается при загрузке. Кнопка «Совместимый просмотр» создаёт локальную MP4-копию с сохранением временной шкалы; для модели сохраняется оригинал. Шрифты включены локально; интерфейс не требует CDN.

Языки интерфейса: русский, казахский, английский. Переключатель в шапке сохраняет выбор в браузере и не сбрасывает видео или результаты. Словарь: `src/translations.json`. Названия брендов, форматы файлов и пользовательские имена файлов сохраняются.

Для реальных результатов модель может вернуть у каждого события `translations: {ru: {type, description, rule?}, kk: {...}, en: {...}}`; `rule` содержит `title`, `section`, `url`. Демособытия переводятся локально. Если модель не предоставила нужный перевод, интерфейс показывает сообщение на выбранном языке вместо текста на другом языке. Облачные переводчики не вызываются.


## Восстановление события, проверка гипотезы и стенд испытаний

В рабочей станции после результата доступны реальные кадры до/в момент/после, увеличение и контекстный фрагмент. Рядом — наблюдения модели и отдельная ручная проверка с экспортом. Во вкладке «Стенд испытаний» можно запускать реальные API-проверки на независимых записях и другой камере, создавать затемнение/размытие/перекрытие и экспортировать измерения. До подключения ML-модуля стенд честно возвращает ошибку, а не синтетические метрики.

[Контракт и инструкция для ML-напарника](docs/ML_HANDOFF.md) · [План съёмки и демонстрации](docs/ANGLE_TEST_PLAN.md).

Установить зависимости `pip install -r backend/requirements.txt`: пакет imageio-ffmpeg включает FFmpeg для поддерживаемой платформы. После установки обработка не требует сети. Для своей сборки можно задать `IMAGEIO_FFMPEG_EXE`. Проверки: `npm run check:features`, `npm run check:i18n`, `python -m pytest backend -q`.


## Портал и Незер

В игровой теме кнопка загрузки на главной — обсидиановый портал. Она переносит на рабочую станцию с анимацией, после чего можно выбрать или перетащить видео. Рабочая станция, лаборатория и панели проверки оформлены в стиле Незера; исходное видео и результаты сохраняются при смене темы. Escape завершает переход, отключение анимаций и prefers-reduced-motion дают мгновенный вход. Фон рисуется локально на Canvas; вкладка в фоне приостанавливает отрисовку. Банковская тема работает независимо.

На игровой главной прокрутка под поверхность открывает каменные слои и заброшенную шахту: опоры, рельсы, вагонетку, паутину и анимированные фонари. Каменная текстура кэшируется, а отрисовка шахты приостанавливается вне экрана. Нижние карточки сохраняют свои функции и переводы. Переключатель делового оформления называется `official`.
