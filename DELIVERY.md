# Передача объединённого приложения

Из корня проекта: `.venv/Scripts/python scripts/start_app.py`.
Интерфейс: http://127.0.0.1:5173; API: http://127.0.0.1:8000.
Загрузите видео и нажмите «Запустить анализ». Настоящая модель включена по умолчанию.
Ключ для прямого API хранится в frontend/.env, в Vite-режиме вручную вводить его не нужно.

Проверены сборка React, переводы, функции стенда и 140 Python-тестов. Настоящий прогон через Vite/API/
локальную модель завершился за 29 с с событием, JPEG-кадрами, нормативной ссылкой и сохранением в истории.
Результаты: reports/integration/report.json. Запуск и установка — README.md.

Модель по качеству осталась прежней: LOVO 17/22 нарушений, 2/20 ложных тревог. Её строгие цели качества
не выполнены; подробности — FINAL_REPORT.md. Интеграция не улучшает распознавание автоматически.
Стенд демонстрации доступен отдельно, его события не считаются результатами анализа.

Wheel в reports/final/packaging содержит только движок; frontend запускается из исходников этого проекта.
Веса исключены из Git и wheel. Публичный URL, HTTPS и Docker объединённого приложения не проверены.
